# Welcome to Atlas

Our shared home for **decisions, delivery, and code**. Everything here is a file in this repository.

## Project overview

Atlas is a small platform that helps teams organize their work without losing ownership of their data.

| Area | Current focus |
| --- | --- |
| Platform | Authentication and repository access |
| Experience | Wiki navigation and task board |
| Delivery | First public proof of concept |

## Working agreements

- Keep tasks small enough to review.
- Record decisions alongside the code.
- Commit documentation with the change it explains.
