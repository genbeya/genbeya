# Marketplace probes (GENBEYA-66)

The empty probe (`genbeya.probe-empty`) was accepted, and the one with all of Genbeya's metadata refused. Each probe here is the empty one plus one piece of that metadata, under its own name. Delete this branch once they are uploaded.

| Probe | Adds |
| --- | --- |
| `genbeya-probe-1-name.vsix` | The display name "Genbeya" |
| `genbeya-probe-2-fields.vsix` | Description, keywords, preview, pricing, author, homepage, bugs, gallery banner, categories, extension kind |
| `genbeya-probe-3-contributes.vsix` | Commands, views, settings, welcome texts, the activity bar icon, workspace trust |
| `genbeya-probe-4-readme.vsix` | The README |
| `genbeya-probe-5-changelog.vsix` | The changelog |
| `genbeya-probe-6-licences.vsix` | `LICENSE.md` (FSL-1.1-ALv2), `LICENSE-MIT-0.md`, `"license": "SEE LICENSE IN LICENSE.md"` |
| `genbeya-probe-7-icon.vsix` | The 128 pixel icon |
