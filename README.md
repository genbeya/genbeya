# Marketplace probes (GENBEYA-66)

Two throwaway packages, to tell whether the Visual Studio Marketplace refuses the `genbeya` publisher, Genbeya's metadata, or its code. Delete this branch once they are uploaded.

- `genbeya-probe-empty.vsix`: a bare extension, `genbeya.probe-empty`. Nothing of Genbeya but the publisher.
- `genbeya-probe-metadata.vsix`: `genbeya.genbeya-probe`, with Genbeya's `package.json`, README, changelog, licences and icons, and empty code.
