Beyond moving tasks between states: everything the app's task details offer, with VS Code's native means (quick picks, input boxes, the editor) and in the task's preview.

- [x] Status, type, priority, assignee, epic, labels and title from the context menu and the preview; custom fields in the preview
- [x] New task with a type, from the type's template; from a board column, in it
- [x] Board: swimlanes per epic, filters (text, assignee, label, priority, type, epic)
- [x] Epics in the Tasks view: a toggle to group by epic, dropping onto an epic moves tasks into it
- [x] Comments: add, edit and delete the user's own, through the content manager
- [x] Activity of a task
- [x] Delete a task; move, rename and delete pages (with link updates)
- [x] Sync the content branch
- [x] Show when the content branch is ahead or behind (in the views' titles)
- [x] Reference, mention and date completion in the comment box
