Beyond moving tasks between states: everything the app's task details offer, with VS Code's native means (quick picks, input boxes, the editor), no webview.

- [ ] Assignee, priority, type, labels, epic and custom fields from the context menu

- [ ] Epics as folders in the Tasks view, or a toggle to group by epic
- [ ] Filter the Tasks view (text, assignee, label, type)
- [ ] Comments: add, edit and delete the user's own, through the content manager
- [ ] Activity of a task
- [ ] Delete a task; move, rename and delete pages (with link updates)
- [ ] Sync the content branch, and show when it is ahead or behind
